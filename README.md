# HỆ THỐNG QUẢN LÝ NHÂN SỰ

## 1. THÔNG TIN SINH VIÊN
- **Họ và tên:** Nguyễn Quốc Sỹ
- **MSSV:** 234232
- **Lớp:** Điện toán đám mây

## 2. MÔ TẢ HỆ THỐNG
Hệ thống quản lý nhân sự trên nền tảng đám mây cho phép thực hiện các chức năng:
- Hiển thị danh sách nhân viên.
- Xem thông tin chi tiết nhân viên.
- Thêm mới hồ sơ nhân viên.
- Tìm kiếm nhân viên theo Mã NV hoặc Họ tên.
- Cập nhật thông tin nhân viên.
- Xóa hồ sơ nhân viên.

## 3. CÔNG NGHỆ SỬ DỤNG
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Version Control:** Git, GitHub
- **Containerization:** Docker, Docker Hub
- **Deployment Platform:** Render

## 4. HƯỚNG DẪN CHẠY MÔI TRƯỜNG PHÁT TRIỂN (DEVELOPMENT)
Backend:
  cd backend
  npm install
  npm run dev

Frontend:
  cd frontend
  npm install
  npm start
